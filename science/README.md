# Scientific route

The problem is to select a known measurement hypothesis by a nonlinear risk from passive classical–quantum examples. The same input context need not recur quickly, and the learner cannot request a fresh specimen at a chosen context.

1. [Model and precise task](model.md): source, hypotheses, loss convention, proper selection, accuracy and resource definitions.
2. [Moment frontier](moment_frontier.md): the exact thresholds $`\Gamma_r`$, inherited polynomial duality, explicit first threshold and limiting behavior.
3. [Passive frontier](passive_frontier.md): the matching fixed-parameter exponent, quantum indistinguishability lower bound and collision-based upper bound.
4. [Replay and resources](replay_and_resources.md): what a repeatable source supplies, how measurements implement the surrogate loss, and which preparation, storage and circuit costs remain.
5. [Interpretation](interpretation.md): scientific consequence, examples and limits.

The main proof has two interfaces: matching low-order moments hides the optimal hypothesis until enough same-context examples arrive; a polynomial envelope makes that number of repetitions sufficient. Neither the scalar moment duality nor the birthday exponents are claimed as new methods. See the [primary comparison](../references/related_work.md).
